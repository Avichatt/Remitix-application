# REMITX

Programmable Cross-Border Payment Network

Starter repository structure for the REMITX hackathon project.

## Initial stack
- Backend: FastAPI
- Database: PostgreSQL
- Frontend: Next.js (to be added)
- Risk Engine: Python / scikit-learn (to be added)
- DLT: DRUNIX integration (to be added)

## Run backend

```cmd
cd backend
uvicorn app.main:app --reload
```

Then open:
- http://127.0.0.1:8000
- http://127.0.0.1:8000/docs
